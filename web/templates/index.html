Pi-side signals (BSC SPI slave, not display SPI0)

  • pi_sck from FPGA → BSC SCLK in (GPIO19 on Pi 3 / Zero2; GPIO11 on Pi 4 per pigpio bsc_xfer mapping)
  • pi_sd from FPGA → BSC MOSI in (GPIO20 on Pi 3; GPIO9 on Pi 4)
  • pi_aln Pi → FPGA: host sets 1 (flush zeros), then 0 for marker + TDM — leave 0 while streaming (default GPIO5)
  • LCD uses SPI0 / GPIO10·11·8·9 + GPIO25/27/12 — keep mic wiring off those pins
